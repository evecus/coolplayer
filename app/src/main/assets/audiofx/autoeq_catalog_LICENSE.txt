Catalog data provenance
-----------------------
Each correction curve in the catalog is derived from third-party frequency
response measurements published by their respective authors, including but not
limited to:

  - oratory1990        (https://www.reddit.com/user/oratory1990)
  - crinacle           (https://www.reddit.com/user/crinacle) — graphiqs / Squig.net
  - Rtings             (https://www.rtings.com)
  - Innerfidelity, Super Review, Headphone.com, and other public databases

This file bundles the pre-processed catalog (TSV) generated by AutoEq.
The "source" column (base64-encoded per row) records the original measurement
author. This attribution notice must be kept intact whenever the catalog is
redistributed.

Revision of the catalog is recorded in the header comment of the .tsv file.
